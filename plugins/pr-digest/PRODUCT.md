# Product

> Inferred by the agent from the codebase and the bb host. Not yet confirmed by the owner.

## Register

product

## Users

Hampus (solo developer, bb power user) opens the bb homepage many times a day to start agent threads. The section sits under the composer, so the reader is mid-task and scans it in seconds.

## Product Purpose

Give a two-second read of yesterday's merged pull requests and every open pull request across the GitHub repos behind the user's bb projects. Success: the user knows what landed and what is still open without opening GitHub.

## Brand Personality

Quiet, exact, native. It should look like bb built it: same type scale, tokens, density, and motion as the host sidebar and GitHub plugin.

## Anti-references

- Dashboard "hero metric" tiles with gradients.
- Card grids, nested cards, badges everywhere.
- Decorative motion, spinners in content, novelty icons.

## Design Principles

- Disappear into the host: reuse bb tokens and affordances; never invent controls.
- Scan first, detail on demand: title and owner first; counts, labels, and sizes recede.
- One accent, used only for state (merged, review requested, approved).
- Every element earns its row: if the meta adds no decision, drop it.

## Accessibility & Inclusion

WCAG AA contrast on all text against bb light and dark themes. Keyboard focus rings on every link and button. Reduced motion honoured. Touch targets at least 32px tall in the desktop density, 44px on coarse pointers.
